# Dasar Teori

<h2>Dasar Teori HTML</h2>

<p align="justify">
HTML (HyperText Markup Language) merupakan bahasa markup standar yang digunakan 
untuk membuat dan menyusun struktur halaman web. HTML berfungsi untuk menampilkan 
berbagai elemen pada halaman website seperti teks, gambar, tabel, formulir, dan 
tautan (link). Dalam penggunaannya, HTML menggunakan tag atau penanda seperti 
&lt;html&gt;, &lt;head&gt;, &lt;body&gt;, &lt;table&gt;, dan &lt;form&gt; untuk mengatur 
struktur dan isi halaman agar dapat ditampilkan dengan baik oleh browser.
</p>
